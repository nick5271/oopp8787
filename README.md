# 暮日防線

免依賴的 2D 橫向殭屍放置遊戲原型，以 HTML Canvas 繪製像素場景。

## 啟動

```sh
cd /workspace/oopp8787
python3 -m http.server 8000 --bind 0.0.0.0
```

使用瀏覽器開啟主機的 8000 連接埠，或在本機直接開啟 `index.html`。

## 玩法

- 倖存者自動射擊從右側來襲的殭屍，擊殺獲得金幣。
- 升級武器傷害、射擊速度和防線装甲；裝甲升級同時修復 60 耐久。
- 空中支援清除當前敵人，冷卻 25 秒。
- 清完一波獲得額外補給並修復 30% 防線。敵人隨波次強化。
- 失守後 4 秒重新挑戰本波，保留金幣與升級。
- 每 5 秒、升級及離開頁面時自動存檔至 localStorage。
- 離線或隱藏分頁補給最多 8 小時，以基礎每秒 0.25 金幣、每級武器增加 15% 計算；離線不推進波次。
- 重新開始需確認，會清除本機進度。不同瀏覽器／來源不共用存檔。

目前是單人原型，無需帳號、API 金鑰或後端服務。素材由程式繪製，不使用外部資源。

## Spine 主角

已接上提供的 Spine 4.3.23 骨架與圖集，使用官方 `@esotericsoftware/spine-canvas` 4.3.13 執行庫（同一 4.3 系列）。`待機` 會循環播放，每次實際開火時觸發 `射擊`，子彈從骨架槍口位置射出。角色合併 `default` 和 `w_b_m1911` 皮膚，以顯示手槍；殭屍仍使用原本圖形。

聊天中的 PNG 預覽無法作為原始檔讀取，因此原始 `human_01.png` 尚未包含在儲存庫內。使用方式：

1. 下載新版 ZIP 並解壓縮，開啟 `index.html`。
2. 在「倖存者日誌」下按「匯入主角貼圖」。
3. 從電腦選擇原始 `human_01.png`（128 × 128、512 KB 以下），即可換成 Spine 主角。

貼圖只在本機瀏覽器讀取，不會上傳。瀏覽器允許 localStorage 時會記住貼圖；不同來源／瀏覽器需要各自匯入。未匯入時仍可使用原本角色遊玩。JSON 和 atlas 已打包成 `assets/hero/hero-data.js`，不依賴網路請求，因此直接開啟 HTML 也能匯入貼圖。更換骨架檔時需要同步更新此資料檔。

第三方 Spine 執行庫授權與版權聲明保留於 `vendor/spine/LICENSE`；使用及散布須遵循該授權。原始角色檔案由使用者提供。

## 自訂背景

在「倖存者日誌」下按「匯入背景」，選擇電腦上的 PNG、JPG 或 WebP。圖片完整顯示、保持原比例，不拉伸或裁切。1200 × 640 圖片會使用 1200 × 640 戰場；1200 × 460 圖片則使用原戰場比例。其他圖片會按比例縮放為 1200 像素寬，支援寬高比 1.5～4、寬度至少 320 像素、單邊最多 8192 像素、檔案最多 8 MB。

較高的背景預設讓角色站在畫面高度 69%（1200 × 640 時約第 442 像素），適合道路位於畫面下半部的背景。可用「角色站立高度」滑桿把主角、殭屍和防線一起移到道路上；Spine 槍口及子彈會同步調整。匯入背景時，原本的天空、建築與避難所不再繪製，防線作為遊戲物件保留。

圖片和站立高度只保存於本機瀏覽器，不會上傳；儲存空間不足時仍可使用，但下次需重新匯入。「恢復原背景」會清除背景設定，保留遊戲進度與已匯入主角。聊天圖片預覽無法直接寫入儲存庫，因此目前沒有內建使用者提供的背景原始檔，需在遊戲中匯入一次。
